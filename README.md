# Investment Week in Review

A weekly investment news dashboard: equities, bonds and rates, central banks and macro, commodities and currencies, corporate earnings, and IPOs and private markets. Each section has an executive summary and a "See more" analysis with sources.

- `index.html` is the latest edition (published every Monday, 08:00 Lisbon time).
- `editions/YYYY-Www.html` keeps each past edition by ISO week.

Nothing here is investment advice.
